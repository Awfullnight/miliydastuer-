# SchoolCounselor — анимированная презентация

Готовый **статический сайт**. Установки Node.js, npm, сборки и базы данных не требуется.

## Что лежит в архиве

- `index.html` — презентация с 10 анимированными слайдами, интерактивной навигацией и школьными фонами (фоновые фотографии уже встроены).
- `favicon.svg` — значок вкладки.
- `.nojekyll` — отключает сборку Jekyll в GitHub Pages.
- `README.md` — эта инструкция.

## Запуск на компьютере

Распакуйте ZIP и дважды нажмите `index.html`. Для проверки как веб-сайта можно открыть папку через локальный сервер (например, в VS Code с Live Server). Презентации не нужен интернет, кроме перехода по ссылке к основному приложению.

## Vercel — через GitHub

1. Создайте **новый репозиторий** на GitHub.
2. **Распакуйте** архив. В репозитории выберите `Add file` → `Upload files` и загрузите файлы из распакованной папки. Важно: файл `index.html` должен быть в корне репозитория, а не внутри дополнительной папки.
3. Откройте https://vercel.com/new и выберите `Import Git Repository`. Подключите нужный репозиторий.
4. В настройках импорта выберите **Framework Preset: Other**. Для `Root Directory` оставьте `./` (корень репозитория). Не указывайте команды сборки или папку `dist` — проект готовый HTML, сборка не требуется.
5. Нажмите `Deploy`. Главная страница будет открываться по адресу, который выдаст Vercel.

**Альтернатива без GitHub:** откройте https://vercel.com/drop и перетащите этот ZIP. В корне архива есть `index.html`.

## GitHub Pages — без Vercel

1. После загрузки файлов откройте `Settings` → `Pages` в репозитории.
2. В разделе `Build and deployment` выберите `Source: Deploy from a branch`, затем `Branch: main`, `Folder: / (root)`, нажмите `Save`.
3. GitHub выдаст ссылку вида `https://ВАШ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/`.

## Если появляется 404 / Page Not Found

- `index.html` должен находиться **в самом корне проекта**, а не в папке `SchoolCounselor_Ready_Project` внутри репозитория.
- Убедитесь, что имя файла точно `index.html` (маленькими буквами), а не `index.html.txt`.
- В Vercel проверьте `Root Directory: ./`, **Framework: Other** и отсутствие ошибочно заданной `Output Directory: dist`.
- В GitHub Pages проверьте `main / (root)` и откройте **именно опубликованную ссылку**, а не URL репозитория на github.com.
- Не открывайте ссылку `sandbox:/...` как обычный сайт: это ссылка для получения файла из ChatGPT, а не опубликованный адрес.

## Управление презентацией

Стрелки клавиатуры ← →, Page Up/Down, Home/End, кнопки на экране, перелистывание свайпом на телефоне, автопоказ и полноэкранный режим.
